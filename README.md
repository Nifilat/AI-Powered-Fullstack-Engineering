## Week 2: Semantic HTML

Built with plain HTML only, with no CSS and no JavaScript.

- **`index.html`**: student profile with basic information, biography, reasons for joining, and programme goals. It uses an accessible `<details>` accordion and a fragment-identifier "Back to top" link.
- **`form.html`**: replica of the [AltSchool signup form](https://portal.altschoolafrica.com/auth/signin?callbackUrl=/&tab=signup), with labelled inputs, a `fieldset`/`legend`, and `autocomplete` hints.

Both pages share a global `<nav>` at the top and a `<footer>` with an address and copyright.

### Running locally

Open `Week2/index.html` in any browser. No build step or dependencies required.
